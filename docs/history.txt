pyklockAuto will [eventually] contain a number of agents that will poll a number of sensors attached to a vehicle [motorbike].
The sensors will primarily monitor gps data and log position - but more may be added.

The main program will collated this data and display the information from either one journey or multiple journeys.
    The main display is probably on a map.

The agents will come shortly.


V2026.14   [7 September 2026]

	Added a saveCPX method to the dfStore.


V2026.13   [27 August 2026]

	When a new gpx file is added, as well as adding to the file store it is also added to a combined journey.
		The combined journey is added to a combined data frame and currently saved as a pickle file.
		This data frame will be save in a gpx form

	Built with Python 3.14.7 and PyQt 6.11.2.
		updated all modules and requirements.txt.

V2026.12   [17 June 2026]

	Amended the add to the list box to always show the last line.
	Attempted to give the map display an auto zoom, so that the route fills more the the display.


V2026.11   [15 June 2026]

	Added the ability to correct the elevation data on a gpx.file
	  This is achieved using the strm database - see https://github.com/tkrajina/srtm.py
	  This is applied to any new files when added to the file store.

	Corrected a bug in the filestore class.  
		When the file store is zapped clear the file store as well as deleting the physical file.


V2026.10   [12 June 2026]

	Added a display Route button.
		This display the selected gpx file as a geo map in a browser using ploty.express.
			The geo map uses a colour map determined by elevation.
		The gpx file is first converted into a Pandas data frame and then passes to ploty.
		The conversion is handled by utils.dataFrameUtils.py.
		The display is handled by classes.displayGPX.py.


V2026.9   [31 May 2026]

	Added top speed to gpxParser - also by AI.
		Displayed in info window.


V2026.8   [30 May 2026]

	If a filename is selected in the file list, an info window pops up.
		The info window displays date, distance, duration, average speed and elevation gain of the journey.
		The information is determined by a file gpxParser, which was generated using AI, by Google Antigravity.


V2026.7   [28 May 2026]

	Implemented the Add All Files - Always available.
		The existing file store is deleted.
		The list view is cleared.
		The file store is re-loaded and the list view is then re-populated


V2026.6   [27 May 2026]

	Implemented the Add New Files - only enabled if new file exist.
		The new files are them added to the filestore, and turn green.
	Implemented a reverse file check.
		For every entry in the file store for a given sub directory, check the file exists.
		If the file isn't there, delete from the file store.

	Removed some unwanted methods from the filestore.

	
V2026.5   [19 May 2026]

	Implemented a file store.
